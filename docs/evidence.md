# Evidence index

The public release separates recorded observations from new package behavior.
Reference JSON files are derived from the complete fixed-horizon 160M, 410M, and
1B cohorts: all three arms and both tapes are included. Their source paths, hashes,
and Git commit are recorded in each file. The generic monitor uses a target-accuracy
crossing; the paper's compound key-dependence acquisition criterion remains in the
original records and table generator.

The forced diagnostic in these cohorts suppresses the **original selected circuit
heads in every arm**, including intact/control-trained models. It is not the
matched-control training mask. The reference metadata records both head sets.
Thus a control-trained model can learn normally while still failing when those
original circuit heads are suppressed during a diagnostic evaluation.

| Research question | Evidence and executable analysis |
|---|---|
| Is the computation needed during acquisition? | Controlled training-only suppression; `fig_rescue.py` |
| Does correct supply restore learning? | Correct/no/wrong activation supply under common restored evaluation; `fig_rescue.py` |
| Does the same tape change its teaching effect? | Fixed order and exact replay; `fig_orders.py` |
| Does lesion location affect recovery? | Selected resets, fresh-state tests, broader lesions, retained computation; `fig_hero.py`, `fig_mechanism.py` and original audits |
| Does the phenomenon survive pretrained models? | Pythia-160M order/replay, target-row suppression, controls, and key dependence; `fig_pythia.py` |
| What happens with larger models and longer training? | Fixed-head trajectories, adaptive interventions, endpoint follow-ups and controls; `fig_scaling.py`, `analysis/tables/scaling.py` |
| Do the controlled follow-ups replicate? | Fresh-state raw records and summaries; `tab_newseeds.tex` generated by `analysis/tables/scaling.py` |

## Reference collections

The original source release is pinned to development commit
`66bee7d06c436ba03929e02345f9d9b92b1f2c09`. The later evidence and implementations
come from `52dc6f20bcae81cf8851dfb97648f0105849f9cc`. Git blob hashes were checked
when assembling the selected later files. ZIP checksums are in `results/artifacts.json`;
every paper input has its own SHA256 inside the input bundle.

The input bundle preserves original numerical records, including unsuccessful
confirmatory criteria and controls relevant to the reported claims. Source hashes
show integrity, not independent proof of when a protocol was registered. Closely
related public pretraining runs and two tapes within a state are not treated as
independent samples by the release.

Intermediate duplicate exports, machine-specific queue logs, and peripheral
attention-edge development are retained in the private development archive. They
are not needed to reconstruct the selected paper figures. The public release does
not reinterpret those studies as positive evidence.

## Analysis changes

Public figure and table scripts use a clean input/output layout. The 6.9B control
file selector is restricted to `control` and `intact` records: the former wildcard
also matched `circuit` and duplicated those curves in the control collection. The
numerical records are unchanged. This is an analysis correction, not a new run.

Other figure transformations preserve the original numerical operations. The
current preprint is built from the authors' September 28 Overleaf export. The
publication edits add author affiliations, a neutral preprint header, PDF
metadata, and the code-availability statement. Scientific text, figures, and
table rows are preserved from that export. `paper/provenance.json` identifies
the source archive and PDF; `results/manifest.json` covers the complete paper
source as well as the reference records.

## Checkpoints and external data

Small-model checkpoint and evaluation-panel artifacts are provided separately.
Public Pythia starting checkpoints are identified in the historical configurations
and model manifests. Large trained endpoints are not included in the default
release. Saved predictions and manipulation checks can be audited without those
weights; new endpoint activation analyses need the corresponding checkpoint.
An omitted or unavailable checkpoint check must be reported as skipped.

enwik8 and pretrained model weights retain their original licenses. The archived
data guide supplies corpus constructors and hashes; download those external
sources separately rather than treating them as MIT-licensed project code.
